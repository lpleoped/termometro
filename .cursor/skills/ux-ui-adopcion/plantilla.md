# Propuesta de experiencia

Una propuesta por problema. Si el registro de QA tiene varios huecos críticos, un flujo; no un rediseño de toda la marca.

```markdown
## Para quién
Facilitador / Integrante / los dos

## Huecos que esta propuesta cierra
- H1, H2… (del registro de qa-huecos-flujo)

## Flujo
1. [Pantalla o momento] — acción primaria — dato que pasa al siguiente
2. …

## Pantallas
### [Nombre en lenguaje de la persona]
- **Trabajo único:**
- **Primaria:**
- **Se ve:**
- **No se ve:**
- **Vacío:**
- **Error:**
- **Éxito:**
- **Copy clave:** título, botón, vacío

## Fricción que se elimina
- Campo / clic / término — por qué sobraba

## Adopción
Cómo llega alguien sin seed ni capacitación al primer índice creíble.

## Qué no cambia
Índice 0–100, ponderaciones, participación, histórico, plan. Sin producto nuevo.

## Criterios de aceptación
- [ ] El facilitador nuevo completa publicar → copiar link → ver índice
- [ ] El integrante termina sin cuenta
- [ ] Cada pantalla tiene una sola primaria
- [ ] Vacío, error y éxito tienen siguiente paso
- [ ] Refrescar no pierde la ronda ni el resultado
```

## Ejemplo de decisión

```markdown
### Ronda abierta
- **Trabajo único:** compartir la ronda con el equipo.
- **Primaria:** Copiar link para el equipo
- **Se ve:** nombre del equipo, cuestionario, cuántas respuestas se esperan, link.
- **No se ve:** ids, ponderaciones, gráfico de resultados.
- **Vacío:** no aplica; a esta pantalla solo se llega al abrir la ronda.
- **Error:** "No se pudo abrir la ronda" + Reintentar.
- **Éxito:** el link queda seleccionado y debajo: "Cuando respondan, vas a ver el termómetro acá" con enlace a resultados.
- **Copy clave:** título "Listo para compartir"; botón "Copiar link para el equipo".
```
