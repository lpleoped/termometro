# Configuración

Hay dos familias.

**De esta cuenta**, y vale para todos tus equipos:

- Inteligencia artificial. La clave del proveedor se carga ahí. Queda en esta instalación y no forma parte del repositorio. Se usa para armar cuestionarios, lecturas y propuestas.
- Uso. El detalle está en [Uso](/ayuda/uso).
- Respaldo. Copia este espacio para llevarlo a otra computadora. La copia no incluye las claves de los proveedores.

**De un equipo**, y cambia solo a ese equipo:

- Contexto. Condiciones del grupo que cambian cómo se lee una ronda y qué acciones se proponen.
- Canal. Publica en Slack cuando vos lo pedís.
- Tareas. Crea una tarea en monday cuando confirmás una acción.

Si todavía no hay un equipo, el contexto, el canal y las tareas esperan a que lo crees.
