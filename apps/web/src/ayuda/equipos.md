# Equipos

Un equipo es el grupo que vas a escuchar. Cada ronda que publiques queda asociada a ese equipo, y el histórico compara las rondas de ese mismo par: equipo y cuestionario.

En el equipo podés anotar quiénes lo integran y un contexto: condiciones del grupo que cambian cómo se lee una ronda y qué acciones se proponen para ese equipo. El contexto de un equipo no se aplica a los demás.

Si todavía no hay una ronda, el panel te lleva a crearla. La ronda es el momento en que el cuestionario está abierto para responder.
