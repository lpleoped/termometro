# Lo escrito

Las preguntas abiertas se leen como temas y señales del conjunto. No suman al [índice](/ayuda/resultados). Una sección que solo tiene este tipo de preguntas puede pesar 0.

El tono de lo escrito aparece cuando hay al menos 3 comentarios. Describe al conjunto. Es una señal agregada: no diagnostica emociones. Toda señal de este tipo queda para que una persona la revise.

En una ronda anónima, esos textos se muestran junto con el resultado agrupado recién cuando se alcanza el mínimo de respuestas. Un comentario puede reconocer a quien lo escribió aunque no lleve su nombre.
