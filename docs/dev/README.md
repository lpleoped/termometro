# Documentación para quien contribuye

Este mapa es para quien va a cambiar el código. La guía de uso, la que lee quien facilita o responde, vive en la aplicación en `/ayuda`.

Leé en este orden:

1. [Arquitectura](./arquitectura.md). Un solo repositorio y dónde está cada capa.
2. [Persistencia](./persistencia.md). JSON y Mongo son adaptadores del mismo contrato.
3. [API](./api.md). Rutas y qué pide autenticación.
4. [Indicadores](./indicadores.md). Cómo se calcula el índice 0–100 y el semáforo.
5. [Corrida local](./corrida-local.md). Dónde están los comandos para levantarlo.

La titularidad y la licencia están en [origen y titularidad](../ORIGEN_Y_TITULARIDAD.md), `LICENSE`, `NOTICE` y `COPYRIGHT`.
