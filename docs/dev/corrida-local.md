# Correr en local

Los comandos para clonar, instalar y levantar el producto están en el [README](../../README.md), sección «Correr en local». La configuración para contribuir está en [CONTRIBUTING](../../CONTRIBUTING.md), sección «Configuración local».

`npm run dev` usa Mongo. `npm run local` y la aplicación de escritorio guardan JSON en esa computadora. Para conocer el producto, `npm run local` abre una instalación vacía y la cuenta se crea en el primer arranque.
